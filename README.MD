# git.guide：Git 入門介紹網站

用簡單的圖解和互動示範，介紹 Git 是怎麼運作的。

## 檔案結構

```
git-site/
├── index.html      網頁內容
├── css/
│   └── style.css   樣式（暖色調）
├── js/
│   └── main.js     互動效果
└── README.md       說明文件
```

## 怎麼打開

直接在瀏覽器打開 `index.html` 即可，不需要安裝任何東西。

## 網站內容

1. 什麼是 Git
2. 三個區域：工作目錄、暫存區、儲存庫
3. 互動示範：修改三個檔案，自己選要 add 哪幾個再 commit
4. 分支
5. 遠端協作：push、pull、clone
6. 回溯：restore、revert、reset 的差別，以及 HEAD detached
7. 常見錯誤：Vim、E325、embedded repository、push 失敗、.gitignore 等
8. 常用指令表（點擊可複製）

## 修改顏色

所有顏色都在 `css/style.css` 最上方的 `:root` 裡，改那裡就能換整個網站的配色。
