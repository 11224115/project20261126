01 · 什麼是 Git

一台專案的時光機

沒有 Git 的時候，我們會存出「報告_最終版_真的最終_v3.docx」。Git 讓你只保留一份檔案，同時記得它所有的過去。

📸

記錄歷史

每次 commit 都會存下整個專案當下的樣子，附上時間、作者和說明。

⏪

隨時回溯

改壞了也不怕，可以比較差異，或直接回到任何一個過去的版本。

🤝

多人協作

每個人在自己的電腦上工作，再把成果合併在一起，不會互相覆蓋。

04 · 分支

開一條平行時間線

想試一個新功能，又怕弄壞原本能用的版本？開一個分支（branch）。在分支上的修改不會影響 main，確定沒問題後再合併（merge）回來。

  • git branch new-idea建立分支
  • git switch new-idea切換過去
  • git switch main回到主線
  • git merge new-idea把成果合併進來

05 · 遠端協作

把儲存庫放上雲端

GitHub、GitLab 這類網站提供「遠端儲存庫」。大家把各自的提交推上去、再拉下來，就能同步進度。

06 · 指令表

最常用的十個指令

點一下指令就能複製。

git init把資料夾變成 Git 專案
git status查看目前狀態
git add .把所有變更放進暫存區
git commit -m "說明"建立一個快照
git log --oneline看歷史紀錄
git diff看改了哪些地方
git branch列出分支
git switch 分支名切換分支
git push上傳到遠端
git pull從遠端下載更新
